## Color Theme System

The platform uses a **Premium Heritage Theme** with carefully curated colors from `globals.css`:

### Primary Brand Colors
| Color | Value | Usage |
|-------|-------|-------|
| **Primary (Indigo-Purple)** | `oklch(0.6 0.2 250)` | Main brand color, active states, primary actions |
| **Secondary (Soft Gold)** | `oklch(0.7 0.15 70)` | Accents, highlights, premium features |
| **Accent (Deep Purple)** | `oklch(0.6 0.2 300)` | Interactive elements, glow effects |

### Background & Surface Colors
| Color | Value | Usage |
|-------|-------|-------|
| **Background** | `oklch(0.05 0.01 240)` | Deep Midnight - Main page background |
| **Card/Panel** | `oklch(0.1 0.02 240)` | Semi-transparent dark - Component surfaces |
| **Foreground** | `oklch(0.98 0 0)` | White - Text and primary content |

### Status & Utility Colors
| Color | Value | Usage |
|-------|-------|-------|
| **Success** | Emerald | Positive signals, gains, confirmations |
| **Warning** | Amber | Caution, alerts, attention needed |
| **Destructive** | Soft Red | Losses, errors, critical alerts |

### Visual Effects
- **Soft Blue Glow**: Indigo with 20% opacity for primary highlights
- **Soft Gold Glow**: Amber with 20% opacity for secondary accents
- **Soft Purple Glow**: Purple with 20% opacity for interactive elements
- **Glass Effect**: Backdrop blur with semi-transparent overlays
- **Neumorphism**: Inset shadows for depth and tactile feel
